# Wardnet 2026.06.00-beta.2

Patch beta following [`2026.06.00-beta.1`](v2026.06.00-beta.1.md), fixing three bugs found during beta.1 testing. Beta builds receive updates via the **beta channel** only — switch to it in **Settings → Updates** to opt in.

## Bug fixes

### Auto-update restart now triggers reliably

After a successful binary swap the daemon was logging "will be restarted by systemd" but never actually initiating the restart — the `CancellationToken` that drives the graceful-shutdown path was never cancelled. The update service now cancels the token immediately after staging completes, letting systemd's `Restart=always` kick in and the post-upgrade runner execute on the way back up. Closes [#518](https://github.com/wardnet/wardnet/pull/518).

### `/` now serves the user PWA

Navigating to the gateway root returned an empty page. The `user-app` dist committed to the repository was a hand-crafted placeholder with no JavaScript bundle. The app is now built from source and embedded in the daemon binary. Closes [#518](https://github.com/wardnet/wardnet/pull/518).

### `/admin-app` no longer shows a blank page

The admin mobile PWA rendered a blank page on first load. Two compounding issues:

1. The `admin-app/dist` committed to the repository was a stale scaffold from the initial PWA scaffolding commit (#488), never rebuilt after the six feature PRs (#492–#516) that implemented the full application.
2. A CSS import-order bug in `admin-app/src/index.css` placed `@import "@wardnet/forge/styles.css"` after a Tailwind `@source` directive. The CSS specification requires all `@import` rules to precede non-import at-rules; Lightning CSS (used by Tailwind v4) silently drops late imports, stripping all design tokens from the compiled stylesheet (4.7 KB tokenless output vs. 66 KB with the full forge palette).

Both issues are fixed: the dist is rebuilt from current source, and the import order is corrected. Closes [#518](https://github.com/wardnet/wardnet/pull/518).

## Upgrading

### Auto-update (beta channel)

Switch to the beta channel in **Settings → Updates**, then apply the update as usual. The daemon binary swap is mediated by the root-owned post-upgrade runner.

### Manual installer

Re-run the installer to pick up the new daemon:

```sh
curl -sSL https://wardnet.network/install.sh | bash
```
